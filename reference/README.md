# Справочные материалы

Исторические бинарные архивы и конфигурации внешних инструментов удалены из
рабочего дерева. Исходный код и проверяемые правила находятся в модулях и
разделе [`docs/`](../docs/README.md). Это исключает попадание старых
снимков, сгенерированных конфигураций и связанных с ними метаданных в
production-архив проекта.

Папка сохранена как место для будущих проверенных материалов: новый файл
добавляется только вместе с описанием происхождения и контрольной суммой.

Каталог `reference/archives` появится в Git вместе с первым материалом: пустые
каталоги Git не хранит. Когда архивов нет, `reference/SHA256SUMS` пуст и проверка
принимает отсутствие каталога. Перечисленный в `SHA256SUMS` архив по-прежнему
обязан присутствовать и совпадать с указанной контрольной суммой.
