# Проверка USB по двум ZIP с телефона (24.09.2026)

Диагностические архивы сборки `0.3.0-dev` в 21:04:58 и 21:05:08
фиксируют одно и то же подключённое устройство: VID:PID `18D1:4EE7`,
разрешение Android `true`, конфигурация 0, интерфейс 0 (`FF/42/01`),
bulk OUT `0x01` и bulk IN `0x81`, оба с `maxPacket=512`.
В событиях зафиксировано получение USB-разрешения; ошибок экспорта не видно.

По сигнатуре это [интерфейс ADB](https://android.googlesource.com/platform/packages/modules/adb/+/refs/heads/main/adb.h#198),
а [Fastboot](https://android.googlesource.com/platform/system/core/+/refs/heads/main/fastboot/fastboot.cpp#247)
использует `FF/42/03`. Сигнатура и разрешение Android не подтверждают
ADB-авторизацию на подключённом устройстве и не доказывают, что состоялся
протокольный обмен. Оба архива описывают режим ADB; Fastboot не наблюдался.

Для сборки `0.4.0-dev` проверяли распознавание режима ADB/Fastboot на экране
и строку `Recognized USB interfaces` в новом ZIP перед реализацией USB-сессии.

## Проверка сборки 0.4.0-dev

ZIP `22-34-41` подтверждает распознавание ADB `18D1:4EE7` и `18D1:4E11`,
после отключения — Fastboot `18D1:D00D`, интерфейс `FF/42/03`, bulk IN
`0x81`, bulk OUT `0x01`, `maxPacket=512`. Разрешение Android для Fastboot
выдано. Ошибок распознавания и экспорта в журнале нет. Реальные Fastboot
запросы эта сборка не отправляла. Следующий аппаратный тест — запрос только
версии протокола через кнопку в `0.5.0-dev` и новый ZIP после его завершения.
