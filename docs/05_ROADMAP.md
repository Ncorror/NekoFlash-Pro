# План и статус

**Единственный источник статуса проекта.** Другие документы описывают цель и правила; что сделано — только здесь. Статус меняется тем же коммитом, что и код.

Версия APK: `0.38.0-dev`

Текущий этап: **Этап 3 — Команды настольных `adb`/`fastboot` поверх нового ядра**

Следующая задача — первый пункт текущего этапа со статусом `нет` или `в архиве`. Порядок пунктов — часть решения, а не подсказка: менять его можно, но не молча (запись в [08_DECISIONS](08_DECISIONS.md)).

## Статусы

| Статус | Значит |
| --- | --- |
| `нет` | работающего пути нет ни здесь, ни в архиве; если код лежит без вызывающего, это сказано в «Где» |
| `в архиве` | код и тесты есть в [архиве](../reference/README.md), сюда не перенесены или ещё не вызываются приложением. Доказательства архива на железе относятся к его APK |
| `в репо` | код и тесты в этом репозитории, production-путь вызывается, CI зелёный; на железе с APK этого репозитория не проверено |
| `проверено` | подтверждено на реальном устройстве с APK этого репозитория; запись — в [07_BUILD_AND_TESTING](07_BUILD_AND_TESTING.md#журнал-проверок-этого-apk) |

Контракт, который никто не вызывает, — не `в репо`: модуль, скопированный из архива, остаётся `в архиве`, пока его не вызывает приложение. Если пункт готов наполовину — его делят на два пункта, а не пишут «частично».

| Пункт | Статус | Где |

| ADB: оболочка с `logcat` изредка обрывается `PAYLOAD_TRANSFER_FAILED` при живом кабеле | `нет` | 3 раза на 0.23.0–0.25.0, причина не установлена; в 0.27.0 отказ пишет `waitedMs`; без обрыва: 40 с на 0.27.0, 6 мин оболочки с `logcat` на 0.30.0 (D051) |
| ADB: после потери рамки строка соединения показывает «Подключено» | `в репо` | `AdbDispatchLoop` сообщает конец транспорта, связь → «Соединение потеряно», интерфейс отпускается; событие `transport_ended` (D051) |
| Разбор команд в типизированные намерения | `проверено` | `:engine` (`TerminalParser`, `FastbootLineParser`, `AdbLineParser`), 23 теста; неизвестный глагол `adb` не становится `shell` |

| `fastboot flash РАЗДЕЛ` с файлом, выбранным через Android: `download` + `flash:` одной операцией | `в репо` | `FastbootLinkController.downloadFrom(then)`: команды идут, только если устройство приняло весь объём с `OKAY` |
| `:engine` без baseline detekt | `в репо` | baseline удалён, парсер разделён на части |
| `--set-active=СЛОТ` вместе с `flash`, `boot` и wire-командами | `в репо` | `set_active` следом в той же операции |
| Слоты как у настольного `fastboot`: `--slot` по `slot-count`, `all` для `flash`/`erase`, без `--slot` — текущий слот, `--set-active` без значения, `set_active`, `fetch` со слотом | `в репо` | `FastbootSlotTargets` по `verify_slot`/`do_for_partitions`: суффикс только при `has-slot` = `yes`; `--slot all flash` грузит файл под каждый слот (`flashImage`); всё до первой команды; D058 |
