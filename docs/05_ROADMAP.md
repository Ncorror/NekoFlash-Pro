# План и статус

**Единственный источник статуса проекта.** Другие документы описывают цель и правила; что сделано — только здесь. Статус меняется тем же коммитом, что и код.

Версия APK: `0.60.0-dev`

Текущий этап: **Этап 3 — Команды настольных `adb`/`fastboot` поверх нового ядра**

Следующая задача — первый пункт текущего этапа со статусом `нет` или `в архиве`. Порядок пунктов — часть решения, а не подсказка: менять его можно, но не молча (запись в [08_DECISIONS](08_DECISIONS.md)).

## Статусы

| Статус | Значит |
| --- | --- |
| `нет` | работающего пути нет ни здесь, ни в архиве; если код лежит без вызывающего, это сказано в «Где» |
| `в архиве` | код и тесты есть в [архиве](../reference/README.md), сюда не перенесены или ещё не вызываются приложением. Доказательства архива на железе относятся к его APK |
| `в репо` | код и тесты в этом репозитории, production-путь вызывается, CI зелёный; на железе с APK этого репозитория не проверено |
| `проверено` | подтверждено на реальном устройстве с APK этого репозитория; запись — в [07_BUILD_AND_TESTING](07_BUILD_AND_TESTING.md#журнал-проверок-этого-apk) |

Контракт, который никто не вызывает, — не `в репо`: модуль, скопированный из архива, остаётся `в архиве`, пока его не вызывает приложение. Если пункт готов наполовину — его делят на два пункта, а не пишут «частично».
