# Продукт и принятые решения

Актуально для репозитория NekoFlash Pro; источник продуктовой идеи — предоставленный `NekoFlash-main.zip` и вложенный legacy. Статус реализации указан отдельно в [плане](06_Roadmap.md).

## Зачем существует NekoFlash

Телефон-хост напрямую управляет другим Android-устройством по USB через ADB, Fastboot и Recovery. NekoFlash — профессиональный инструмент: быстрые типизированные действия и полноценные консоли используют одно протокольное ядро. Mi Unlock — будущий самостоятельный сценарий поверх общих Fastboot/USB API и отдельного vendor/network слоя.

Полный охват legacy — цель, а не утверждение о нынешнем APK. Нужны Shell и файлы ADB, Sideload с отдельным вердиктом установки, Fastboot flash/boot/erase/format/слоты/fastbootd, диагностика и управляемые длительные операции. Конкретный перечень — в [матрице возможностей](00_Command_Parity_P0.md).

## Вид и взаимодействие

- Бренд — **NekoFlash**; слово Pro в названии репозитория и текущем APK обозначает текущую линию разработки. Визуальные референсы Welcome, кота/USB и иконки берутся из вложенного legacy, старую разметку не переносим.
- Тема приложения тёмная: базовый фон `#080D13`, карточки `#121A24`, действия `#E9782B`, нажатие `#CC5D18`, основной текст `#F3F6FA`. Холодный цвет допустим для технологических статусов, основное действие остаётся оранжевым.
- Домашний экран показывает выбранное устройство, режим, текущую USB-сессию и результат операции. Подробные endpoint/протокольные сведения находятся в диагностике. Welcome не блокирует доступ к функциям.
- Разрешение USB запрашивается в контексте распознанного устройства. При одном надёжно классифицированном ADB-устройстве после разрешения начинается соединение, а для неизвестного ключа появляется стандартное подтверждение отладки **на целевом устройстве**. При неоднозначном USB-интерфейсе пользователь выбирает вручную. Fastboot при подключении не начинает запись.
- Языки интерфейса: русский и английский. Точный текст ответа устройства и команды протокола не переводятся.

## Права пользователя и технические границы

Приложение не вводит отдельные профили «новичок/эксперт» и списки разрешённых производителей или разделов. Guided UI объясняет риск и просит явное подтверждение для разрушающего действия. Подтверждённый `LOCKED` — сильное предупреждение и ввод `yes` перед записью в guided UI; собственный Fastboot engine не подменяет отказ устройства. `UNKNOWN` не означает `LOCKED`. Сырая консоль передаёт валидный запрос устройству и показывает его ответ.

Технические проверки обязательны: корректный wire-формат, актуальная USB-generation, точное число передаваемых байтов, стабильность выбранного файла, реальное владение соединением. Если после возможной записи результат неизвестен, показываем `Unknown` и не делаем автоматический повтор. `max-download-size`, размер раздела и состояние загрузчика показываются как сведения/предупреждения; если конкретную передачу нельзя корректно закодировать в протоколе, её нельзя отправлять.

**Расхождение, которое предстоит исправить в коде:** нынешний исполнитель Fastboot останавливает запись при неизвестном `max-download-size` или `partition-size` и пока не умеет sparse/большие образы. В целевой архитектуре эти сведения сами по себе не являются системой разрешений; алгоритм переноса и его проверки ещё нужно спроектировать. Смена текста документа не меняет поведение APK.

Пакет `com.ncorror.nekoflash.pro` пока сохраняется ради уже установленного прототипа и его ADB-ключа. ID архивной реализации `io.github.ncorror.nekoflash` не переносится автоматически. Любая смена ID и подписи — отдельное решение перед миграцией.
