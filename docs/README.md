# Документация NekoFlash

Единственная карта документов проекта. Каждый факт живёт ровно в одном документе — его **владельце**. Остальные документы на него ссылаются, но не пересказывают: пересказ устаревает первым.

## Порядок чтения

Новая сессия (человек или агент) читает в этом порядке. Других списков нет.

1. [01_PRODUCT](01_PRODUCT.md) — что строим, для кого, чего не делаем никогда.
2. [02_INVARIANTS](02_INVARIANTS.md) — когда операцию можно остановить и какие протокольные правила нельзя нарушать.
3. [03_ARCHITECTURE](03_ARCHITECTURE.md) — слои, модули, направление зависимостей, стандарт кода.
4. [05_ROADMAP](05_ROADMAP.md) — текущий этап и статус каждого пункта. **Следующая задача — первый пункт текущего этапа, который ещё не в статусе `в репо` или `проверено`.**
5. [06_MIGRATION](06_MIGRATION.md) — если задача касается переноса кода из архива.
6. [07_BUILD_AND_TESTING](07_BUILD_AND_TESTING.md) — сборка, CI, проверка на телефоне, что уже доказано на железе.

По необходимости: [04_CAPABILITIES](04_CAPABILITIES.md) — полный целевой набор функций; [08_DECISIONS](08_DECISIONS.md) и ADR — почему решено именно так.

## Правила ведения

1. **Тот же коммит.** Изменение кода, поведения, CI, процесса или статуса обновляет документ-владелец в том же коммите. Работа без обновлённого документа не считается сделанной.
2. **Статус — только в [05_ROADMAP](05_ROADMAP.md).** В других документах нет слов «готово», «сделано», «работает» о пунктах плана; они ссылаются на план.
3. **Решение — строка в [08_DECISIONS](08_DECISIONS.md).** Если его трудно отменить или у него были серьёзные альтернативы — ещё и ADR.
4. **Нового документа не бывает без строки в таблице выше.** Лучше дописать раздел к владельцу, чем завести девятый файл.
5. **Устаревшее удаляется, а не помечается.** История остаётся в git и в архиве; в `docs/` лежит только действующее.
6. **Проверка машиной.** `python3 scripts/ci/check_docs.py` запускается перед коммитом и в CI. Что она сверяет — в [07_BUILD_AND_TESTING](07_BUILD_AND_TESTING.md#проверка-документации).

Справочные архивы и правила обращения с ними — [`reference/README.md`](../reference/README.md).
