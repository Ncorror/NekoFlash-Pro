# Документация NekoFlash Pro

Здесь единая рабочая версия идеи после сверки трёх кодовых баз: текущего `NekoFlash-Pro`, предоставленного рефакторинга `NekoFlash-main.zip` и вложенного в него legacy; снимок A2 внутри архива — отдельный источник протокольных решений. Это **не** механическое копирование больших дневников и чеклистов из архива.

| Документ | Что искать |
| --- | --- |
| [01_Decisions](01_Decisions.md) | цель продукта, внешний вид, права и текущие спорные правила |
| [04_Architecture](04_Architecture.md) | границы модулей, транспорт, операции, файлы и инварианты |
| [00_Command_Parity_P0](00_Command_Parity_P0.md) | конечные возможности и смысл `raw`/host-команд |
| [05_Source_Comparison](05_Source_Comparison.md) | что есть в каждом источнике и что брать из legacy/A2 |
| [06_Roadmap](06_Roadmap.md) | готовность **этого репозитория** и порядок переноса |
| [02_Manual_Test_Plan](02_Manual_Test_Plan.md) | сборка, Termux, диагностика и будущие аппаратные проверки |
| [03_Usb_Observation](03_Usb_Observation.md) | общие уже установленные факты USB без выгрузки частных логов |

**Как читать статусы:** целевая возможность ≠ файл в рефакторинге ≠ функция в APK из этого репозитория ≠ проверка на реальном устройстве. Факт текущей реализации устанавливают исходники и CI здесь, а аппаратный статус — отдельно проверенный прогон этой сборки. Исторические утверждения внутри архива относятся к тому архиву.

При расхождении ориентируемся на явную договорённость с владельцем проекта, затем на [решения](01_Decisions.md), технические [инварианты](04_Architecture.md), [статус](06_Roadmap.md) и исходники текущего репозитория. Архивные заметки и вложенные снимки legacy/A2 — источники опыта, а не инструкции к неподготовленным операциям.

Изменение функции обновляет статус, ручную проверку и ссылки одним набором правок. Частные USB-логи, серийные номера, ключи и отчёты с телефона не помещаются в репозиторий; их сохраняют локально и передают отдельно по необходимости.
