# NekoFlash

Профессиональный инструмент на Android-телефоне, который напрямую по USB управляет другим Android-устройством: ADB, Fastboot и fastbootd, Recovery и Sideload, настоящий терминал, долгие операции с большими образами, диагностика и, в дальнейшем, Mi Unlock. Компьютер и root на телефоне-хосте не нужны.

Главный принцип — никаких искусственных ограничений: приложение предупреждает и спрашивает подтверждение, но не отнимает валидные возможности протоколов; отказывать может только само устройство или нарушенный инвариант протокола.
