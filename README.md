# NekoFlash Pro

Android-приложение, которое работает как USB-хост для другого Android-устройства: ADB, Fastboot, Recovery и, в дальнейшем, Mi Unlock. Для работы с подключённым устройством компьютеру и root на телефоне-хосте не нужны.

**Сейчас в этом репозитории — технический прототип `0.19.0-dev`.** Он обнаруживает USB-интерфейсы, запрашивает разрешение Android, автоматически начинает ADB-авторизацию, умеет несколько диагностических команд и содержит ограниченный путь Fastboot DATA OUT/`flash`. Успешная запись раздела на реальном устройстве не подтверждена. Интерфейс и терминал ещё не соответствуют полной функциональности NekoFlash.

Предоставленный архив `NekoFlash-main.zip` содержит более развитую **отдельную** реализацию: USB/session model, многопоточный ADB, расширенный Fastboot, операции, работу с файлами и тесты. Внутри есть исходники legacy и A2 как исторические образцы. Код архива пока **не объединён** с этим репозиторием; наличие функции в архиве не означает, что она доступна в здешнем APK.

## Сборка текущего репозитория

JDK 17 и Android SDK 36; для воспроизводимой сборки используйте проверяемый Gradle Wrapper:

```sh
bash ./gradlew :engine:test :core:transport:test :core:fastboot:test :core:adb:test :core:diagnostics:test :app:lintDebug :app:assembleDebug --no-daemon
```

APK появится в `app/build/outputs/apk/debug/`. GitHub Actions выполняет те же проверки при push и публикует APK вместе с отчётами тестов. Termux нужен для Git/`gh` и отправки изменений; локально собирать Android APK в Termux не требуется. [Инструкция и границы проверок](docs/02_Manual_Test_Plan.md).

Текущий `applicationId` — `com.ncorror.nekoflash.pro`; в приложенном архиве иной ID — `io.github.ncorror.nekoflash`. До миграции кода эти проекты нельзя считать взаимозаменяемыми APK. Сохраняем тёмную тему и основной оранжевый `#E9782B` из legacy.
